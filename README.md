# 작은 탐정단: 반짝이는 다섯 가지 사건

치이카와, 하치와레, 우사기와 함께 단서를 찾는 초등학교 5~6학년용 비공식 팬 추리 게임입니다.

## 실행하기

저장소를 다운로드한 뒤 [`index.html`](index.html)을 브라우저에서 열면 됩니다. HTML, CSS, JavaScript, 그림, 짧은 모션 영상이 저장소에 함께 들어 있습니다.

## 게임 구성

- 5개 사건, 사건마다 4단계 추리
- 단서 카드를 눌러 확인하고, 오답은 횟수 제한 없이 다시 시도
- 단계마다 두 번의 힌트, 추리 수첩과 진행 기록
- 사건별 상황 그림과 짧은 모션 영상, 움직임 끄기 및 소리 설정

게임 진행 기록은 사용 중인 브라우저에 저장됩니다. 캐릭터를 활용한 비공식 팬 작품입니다.
